# AC3E chip

The AC3E chip in one `chip_top.gds`: the 108-pad AC3E ring, the croc_soc hard macro and the DC-DC layouts of
S. Sanchez. Built with LibreLane from the wafer.space GF180MCU project template (Apache-2.0, see `LICENSE`).

```
make macro RUN=<croc run>    # croc_soc views from a manquehue_chip run
make chip                    # LibreLane: pad ring, croc_soc, wires
make merge                   # DC-DC layouts into the GDS
make gls precheck summary
```

`make help` lists every target. The guide (`ac3e_chip_guide.pdf`) has the recipes: a new CROC macro, new DC-DC
layouts, a pad ring change, a new pad.

| Folder | What is here |
|---|---|
| `librelane/` | Flow configuration: `config.yaml`, `slots/slot_ac3e.yaml`, `macros/macros.yaml`, `pdn/`, `padframe/` |
| `src/` | `chip_top.sv` (generated by `make ring`) and `chip_core.sv` (croc_soc and its pad controls) |
| `scripts/` | `gen_chip_ring.py`, `merge_dcdc.py`, `render_gds.py` |
| `ip/` | wafer.space ID cells |
| `macros/` | Inputs, not in Git: `croc` (link to the croc run), `dcdc_v0` (V0 DC-DC layouts), `dcdc_old` (earlier ones, used by the manquehue_chip FC chip flow) |
| `out/` | Logs and results of the targets, not in Git |

The pad ring comes from `scripts/chip/padring.txt` of manquehue_chip, the same table that places the croc_soc pins.
